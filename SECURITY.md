# Security

Please report a security problem privately, through GitHub's private vulnerability reporting: the **Security** tab of
this repository › **Report a vulnerability**. Don't open a public issue for it.

Useful to include: the GrindPilot version (Inputs and status › Version), what you did, and what happened. Please leave
out screenshots that show other players' names.

GrindPilot is a hobby project with no support promise; reports are read and answered as time allows.
